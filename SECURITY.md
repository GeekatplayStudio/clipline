# Security Policy

Do not open public issues for suspected vulnerabilities. Report them privately through the repository host's
security-advisory feature and include affected versions, reproduction steps, impact, and any suggested mitigation.

Only the latest `main` revision is currently supported. Never include customer data, credentials, API tokens, or
other secrets in a report. The maintainers will acknowledge a complete report within five business days and will
coordinate validation, remediation, and disclosure with the reporter.
